# Third-party notice — Hyser open EMG toolbox functions

The MATLAB functions under `toolbox/function/` come from the open processing
toolbox released with the Hyser dataset (Jiang et al., IEEE TNSRE 2021).

- Dataset DOI: https://doi.org/10.13026/ym7v-bh53  
- Paper DOI: https://doi.org/10.1109/TNSRE.2021.3082551  

They are included here so the driver scripts in `scripts/` run as a single
repository. Credit remains with the original authors. If you redistribute,
keep this notice and cite the paper/dataset.
